### 🧠 FedRAPT

**Personalized Federated Learning for Wearable Sensor-based Human Activity Recognition**

FedRAPT is a personalized federated learning framework designed for
human activity recognition using heterogeneous wearable sensor data.

#### Research Focus

* Personalized learning under non-IID client data
* Wearable sensor-based human activity recognition
* Federated model training and evaluation
* Performance analysis across heterogeneous users
