# 🧠 FedRAPT

### Personalized Federated Learning for

### Wearable Sensor-based Human Activity Recognition

</div>

FedRAPT is a personalized federated learning framework designed to improve
human activity recognition performance using heterogeneous wearable sensor data.

### 🔍 Research Focus

* Personalized federated learning under non-IID client data
* Wearable sensor-based human activity recognition
* Local and global model training
* Performance comparison across heterogeneous users
* Federated model training and evaluation pipelines
